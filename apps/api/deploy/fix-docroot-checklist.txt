HOSTINGER API ROUTING HOTFIX (api.smartfashion.site)
====================================================

ROOT CAUSE (common): public_html/api/ exists as a folder, so /api/v1/* never
reaches Laravel. Fix: install index.php + .htaccess inside public_html/api/.

ON SERVER (SSH):
  cd ~/domains/api.smartfashion.site/private/smartfashion-api
  git pull
  bash deploy/apply-hostinger-routing.sh

MANUAL (if no git):
  Copy deploy/hostinger-* to public_html per apply-hostinger-routing.sh

VERIFY:
  curl -sS -H 'Accept: application/json' https://api.smartfashion.site/up
  curl -sS -H 'Accept: application/json' 'https://api.smartfashion.site/api/v1/categories?perPage=1'
  curl -sS -H 'Accept: application/json' 'https://api.smartfashion.site/api/v1/products?perPage=1'

EXPECT: JSON (not HTML). /up => {"status":"ok"} or similar.

SMOKE:
  STAGING_API=https://api.smartfashion.site ADMIN_PASSWORD='***' bash deploy/smoke-staging.sh

.env:
  APP_URL=https://api.smartfashion.site
  APP_DEBUG=false
